# Nexora 3D Companion Models Directory

Place your custom Blender `.glb` or `.gltf` 3D character models in this folder.
You can load them directly inside Nexora by entering `/models/your_character.glb` or by using the in-app 3D companion model uploader!

Recommended 3D Character Rigging & Animation Mapping:
- **Idle**: Breathing, blinking, hovering
- **Walk**: Running, hopping, gliding
- **Jump / Celebrate**: Victory backflip, cheering hands
- **Talk**: Mouth open/close, hand gesturing
- **Focus**: Calm hover, meditative seated pose
